# Just a simple program to find all pdf files with a given word

## Setup 

### 1. Clone the repository
```
git clone https://github.com/salvatorecalo/search_pdf_files_with_specific_word.git
```

### 2. create enviroement
```
python3 -m venv venv
```

### 3. activate enviroement and install deps
```
source venv/bin/activate (Macos/Linux)

.\venv\Scrips\activate (Windows)
```
